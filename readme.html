# 🎯 Dart Match App (Live Toernooi Tracker) Dart Match App is een Progressive Web App (PWA) voor live darttoernooien. De app leest DartConnect-data uit, toont alleen de relevante wedstrijden voor geselecteerde spelers en verstuurt persoonlijke pushmeldingen wanneer een speler moet spelen of schrijven. De app is bedoeld voor toernooien met één of meerdere fasen, zoals poules, winnaarsronde en verliezersronde. Naast live wedstrijden kan de app ook live poulestanden tonen via de Round Robin-data van DartConnect. > Let op: de app gebruikt onofficiële/afgeleide DartConnect-endpoints. Als DartConnect routes of veldnamen wijzigt, kan parsing aangepast moeten worden. --- ## ✨ Belangrijkste functies ### Voor spelers - **Toernooioverzicht** met publieke en zelf toegevoegde toernooien. - **Wedstrijdstatussen**: live/bezig, gepland, mogelijk volgende ronde en gespeeld. - **Live scores** inclusief score-update highlight. - **DartConnect live-link** via watch/spectator key wanneer een wedstrijd live is. - **Recap-link** naar DartConnect Recap voor gespeelde wedstrijden. - **Bordnummer, ronde, match-id, schrijver/marker en gemiddelden** waar beschikbaar. - **Live poulestanden** via de knop `📊 Live Stand Poules`. - **Persoonlijke pushmeldingen** per toernooi en per speler. - **Zelf toernooi toevoegen** als verborgen/user toernooi. - **PWA-installatie** op Android en iOS, inclusief iOS-installatiehint. ### Voor beheer - **Beveiligd admin-paneel** via Basic Auth. - **Toernooien toevoegen, bewerken en verwijderen**. - **Verborgen/user toernooien** markeren. - **Ondersteuning voor meerdere toernooi-opzetten**: - Enkel schema. - Poules + knockout. - Poules + winnaarsronde + verliezersronde. - **Automatische DartConnect URL-vertaling** van pagina-links naar API-links. - **Spelers importeren/ophalen** vanuit de gekoppelde DartConnect-bron. - **Darters per toernooi beheren**. - **Handmatige pushmelding** naar alle actieve abonnees. --- ## 🧩 Hoe de app globaal werkt Gebruiker/Admin ↓ Frontend PWA: public/index.html + public/admin.html ↓ Node/Express backend: server/server.js ↓ DartConnect endpoints ↓ Genormaliseerde data terug naar de app De backend fungeert als proxy en normalisatielaag. De frontend roept dus niet rechtstreeks DartConnect aan, maar gebruikt de eigen backend-routes zoals `/api/matches` en `/api/poule-standings`. --- ## 📂 Mapstructuur matchapp/ │ ├── public/ │ ├── index.html # Hoofd-app voor spelers │ ├── admin.html # Beveiligd beheerpaneel │ ├── manifest.json # PWA-configuratie │ ├── service-worker.js # Offline cache + push notification handler │ └── icon-192x192.png # App-icoon │ ├── server/ │ ├── server.js # Express server, DartConnect proxy en pushlogica │ └── database.json # Wordt automatisch aangemaakt/gebruikt │ └── README.md --- ## 🚀 Installatie ### 1. De app vertaalt die naar een API-link. ### Belangrijk verschil | DartConnect API | Bevat | |---|---| | `/api/event/{event}/bracket/{eventId}` | Wedstrijden, schema, scores per match | | `/api/event/{event}/round-robin/{eventId}` | Ploeg-/spelerstanden per poule | | `/event/{event}/state/matches?fetch_type=initial` | Live/completed match-state | | `/api/event/{event}/confirmation/{eventId}/players` | Ingeschreven/confirmed spelers vóór de loting | --- ## 📊 Live poulestanden De knop `📊 Live Stand Poules` opent een modal in de app. De frontend roept daarvoor aan: GET /api/poule-standings?tournament=TOERNOOINAAM De backend zoekt de eerste poule-/bracket-link van het toernooi, zet die om naar `/round-robin/` en leest de `roster` uit. De response wordt gegroepeerd per poule. Velden die worden gebruikt: | Veld | Betekenis | |---|---| | `opponent` | Spelernaam | | `rr_group` | Pouleletter | | `mp` | Matches played | | `mw` | Matches won | | `gld` | Leg difference | | `lw` | Legs won | | `ppr` | Gemiddelde, indien beschikbaar | | `init_rank` / `final_rank` | Ranking/positie | --- ## 🎯 Wedstrijddata en live scoring De centrale functie `fetchMatchesForTournament()` in `server.js` haalt data uit de gekoppelde DartConnect-bronnen en normaliseert alles naar één formaat voor de frontend. De app combineert o.a.: - bracket-/poulewedstrijden; - DartConnect state data voor live en gespeelde wedstrijden; - speler-id naar naam mapping; - live scores; - writer/marker informatie; - bordnummer; - watch/spectator key; - recap-id; - rondeherkenning voor poules, winnaarsronde en verliezersronde. De frontend toont wedstrijden als: bezig → live wedstrijden gepland → bekende komende wedstrijden mogelijk → mogelijke volgende ronde gespeeld → afgeronde wedstrijden --- ## 🔔 Pushmeldingen De app gebruikt Web Push via `web-push` en automatisch gegenereerde VAPID keys. Subscriptions worden opgeslagen in `server/database.json`. Gebruikers kunnen per toernooi kiezen voor welke spelers ze meldingen willen ontvangen. De app gebruikt daarbij: - de geconfigureerde darters in de backend; - opgeslagen voorkeuren in `localStorage`; - spelers die via DartConnect preview/import beschikbaar zijn. Pushmeldingen worden gebruikt voor o.a.: - nieuwe geplande wedstrijd; - wedstrijd binnen ongeveer 10 minuten; - poule-indeling bekend; - marker/schrijver-taak; - handmatige admin-omroep. ### iOS Op iOS werken pushmeldingen alleen betrouwbaar als de gebruiker de app op het beginscherm heeft gezet via het deelmenu. De app toont hiervoor een iOS-installatiebanner. --- ## ⚙️ Admin-handleiding 1. Open `/admin.html`. 2. Log in met de ingestelde Basic Auth-gegevens. 3. Voeg een toernooi toe: - Vul een naam in. - Kies de opzet. - Plak de DartConnect links. - Markeer eventueel als verborgen/user toernooi. 4. Sla het toernooi op. 5. Selecteer het toernooi bij “Darters per Toernooi”. 6. Voeg de relevante spelers toe. 7. Klik op “Alles Opslaan”. ### Toernooi-opzetten | Opzet | Gebruik | |---|---| | Enkel schema | Alleen knockout of alleen poule | | Poules + hoofdschema | Poules gevolgd door knockout | | Poules + winnaarsronde + verliezersronde | Poules gevolgd door WR en VR | --- ## 👤 Zelf toernooi toevoegen door gebruiker In de hoofd-app kan een gebruiker zelf een toernooi toevoegen. Dit toernooi wordt als `unlisted` opgeslagen en verschijnt alleen voor die gebruiker via `localStorage`. Stappen: 1. Klik op `➕ Zelf toernooi toevoegen`. 2. Vul toernooinaam en DartConnect-links in. 3. Laat de app spelers ophalen. 4. Selecteer spelers voor meldingen. 5. Sla op. --- ## 🗄️ database.json De server maakt/gebruikt `server/database.json` als eenvoudige opslag. Belangrijke onderdelen: { "tournaments": [], "subscriptions": [], "notifiedMatches": [], "notifiedPoules": [], "vapidKeys": {} } ### Toernooi-object { "name": "Voorbeeld Toernooi", "url": "https://tv.dartconnect.com/api/event/.../bracket/192955", "matchlistUrl": "", "darters": ["Speler, Naam"], "unlisted": false } --- ## ⏱️ Caching en verversing - De frontend ververst wedstrijddata elke 10 seconden. - De backend gebruikt een korte match-cache van ongeveer 10 seconden. - De heartbeat draait periodiek en vult de cache alvast. - Scorewijzigingen krijgen in de frontend een visuele flash. - Bij terugkeer naar de app (`visibilitychange`) wordt direct opnieuw ververst. --- ## 🔐 Security-aandachtspunten - Wijzig altijd de standaard admin-login. - Plaats de app achter HTTPS. - Houd `database.json` buiten publieke statische mappen. - Deel geen cookies, tokens of DartConnect-dumps publiek. - Overweeg environment variables voor admin-login en VAPID-contactadres. --- ## 🧭 Roadmap / ideeën - Per gebruiker meerdere spelerslijsten/profielen. --- ## Korte samenvatting Deze app volgt live darttoernooien, filtert wedstrijden op gekozen spelers, toont live scores en poulestanden, en stuurt slimme pushmeldingen wanneer spelers moeten spelen of schrijven. De backend normaliseert DartConnect-data zodat de frontend eenvoudig en snel blijft.
